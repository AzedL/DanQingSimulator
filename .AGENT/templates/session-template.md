# 会话模板

## 索引信息

- 主题：用于索引和快速检索
- 描述：用于帮助判断该会话是否值得继续阅读

## 会话工作信息

- 优先记录本轮真正有价值的工作信息：主要任务，背景，涉及范围，关键决策，高风险点，踩坑，边界，验证结论等
- 根据内容自由调整格式和写法，但应便于后续回看
- 不写完整流水账，不机械罗列每一步操作

## 对 `summary.md` 的改动建议

### 删除

- 写已错误、过时、被推翻或已无参考价值的内容

### 修改

- 写仍然有效，但表述、路径、命名或范围需要修正的内容

### 新增

- 写本轮新确认、且值得进入 `summary.md` 长期上下文的最小新增内容
- 必要的历史索引入口
