# `.AGENT` 入口与使用说明

本文件为 `.AGENT/index.md`，是 `.AGENT` 目录的默认入口。
新会话默认先阅读本文件，再按本文规则决定是否继续阅读 `summary.md`、`rules/*.md` 与其他文件。

`.AGENT` 不是正式项目文档，不替代 README，也不作为面向用户或团队成员的唯一规范来源。

## 阅读规则

除非任务小到无需项目上下文，否则 agent 应先完成最小必要阅读，再进行大范围搜索、跨模块重构或实际代码修改。
默认不查阅历史 `sessions/*.md`，除非当前任务确实需要追溯其来源。

默认先阅读以下文件：

1. `index.md`
2. `summary.md`

为了定位任务相关文件而进行的小范围检索不受此限制，例如文本搜索、符号跳转、引用查找和打开少量直接相关文件。

只有在以下情况，才继续阅读其他文件：

1. 当前任务涉及特定模块，需要查看对应的 `rules/*.md`
2. `summary.md` 明确引用了与当前任务相关的 `rules/*.md`
3. 需要追溯某个历史决策、回归、性能结论或争议来源
4. 当前任务明确延续某一轮历史会话

## 小任务豁免

如果任务仅属于以下情况，可跳过完整阅读流程，直接执行：

1. 查找某个函数、类型或文件位置
2. 解释局部代码
3. 修改注释、文案或格式
4. 单行或极小范围的低风险修复

一旦任务超出局部低风险范围，就回到最小必要阅读流程。

## 模块命中规则

当任务的修改、验证或定位明显依赖某模块的兼容语义、计算规则或默认验证方式时，必须阅读对应的 `rules/*.md`。
是否命中模块，不以是否直接出现模块名作为唯一判断依据。

常见命中示例如下：

1. 涉及自动模拟、配卡搜索、结果筛选或组合枚举
   - 读取 `rules/autoMock.md`
2. 涉及 `kernel`、模拟执行、伤害结算或 tick 行为
   - 读取 `rules/kernel.md`
3. 涉及领域配置、数值推导、`deriveStats`、数据来源或映射
   - 读取 `rules/domain.md`

如果一个任务同时命中多个区域，则按需读取多个规则文件。

## 文件职责

### `summary.md`

- 作为默认的项目上下文主入口使用
- 只保留当前仍然有效、且对后续会话最有价值的信息

### `rules/*.md`

- 记录模块级长期规则
- 重点记录高风险边界、常见陷阱与默认验证方式
- 保持简短、明确、可执行

### `sessions/*.md`

- 记录可检索的会话信息，供后续追溯与归档使用
- 保留索引信息、会话工作信息，以及对 `summary.md` 的改动建议
- 不作为完整流水账使用

## 维护原则

- `index.md` 只保留入口规则、阅读边界、文件职责与最少量的维护原则
- 模块细节和扩展约束优先下沉到 `rules/*.md`

## 归档

- 归档只在用户明确要求时执行
- 执行归档时，阅读 `archive.md`
