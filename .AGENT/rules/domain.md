# Domain 规则

本文件记录 `src/domain/**` 相关的长期规则。

## 适用范围

- `src/domain/rules/**`
- `src/domain/cards/**`
- `src/domain/config/**`

## 长期规则

- `src/domain/rules/deriveStats.ts` 属于高风险文件，改动时优先考虑兼容语义和数值回归
- 不要因为“看起来更合理”就删掉旧行为；先确认当前结果是否依赖该兼容语义
- 默认模拟配置应继续集中在 `src/domain/config`
- 新代码优先从 `domain` 暴露稳定数据和规则，不要把业务逻辑重新塞回 UI 层

## 特别注意

- `yanHong`
- `zheShan`
- `xingHongJuYi`

这三种基础伤害在未携带对应主卡时，当前仍沿用旧语义，以 `level = -1` 参与基础倍率计算。

不要把这条行为直接改成按 `0` 处理，除非已经有明确的行为迁移方案和验证结果。

## 默认验证

- 至少检查默认卡组的关键结果
- 重点核对总 DPS、燃烧伤害、燃烧占比、爆燃相关结果
- 如果只改配置或元数据，也要确认没有影响到核心推导链路
