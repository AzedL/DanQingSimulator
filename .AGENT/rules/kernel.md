# Kernel 规则

本文件记录 `src/kernel/**` 以及核心模拟流程相关的长期规则。

## 适用范围

- `src/kernel/**`
- `src/engine/Simulation.ts`

## 长期规则

- 旧模拟内核继续保留，不要轻易尝试整套重写
- 当前方向是收口外围层，而不是改写核心模拟逻辑
- 如果必须改动核心行为，先确认是修 bug 还是语义变更，不要混在一起做
- 内核相关修改优先做小闭环，不要一轮同时做大面积结构整理和行为调整

## 默认验证

- 至少核对 600 秒默认结果没有明显回归
- 如果变更涉及伤害、冷却、触发逻辑，优先补回归测试或对照结果
- 如果只改导入或目录边界，也建议补一次类型检查
